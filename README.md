# Arcwrite

AI-assisted interactive fiction platform. Create branching choose-your-own-adventure stories.

## Development

```bash
npm install
npm run dev       # Dev server (Vercel dev on port 8080)
npm run build     # Production build
npm run lint      # ESLint
npm run test      # Unit tests
```

## Deployment

Deployed on Vercel. API routes live in `api/` (Edge + Node.js Functions).

## Stack

React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, Supabase, Stripe, OpenAI
